# Portfolio workflow

- Treat local development as the staging environment.
- Collect and batch requested website updates locally.
- Validate related updates together before release.
- Do not deploy, publish, push to Netlify, or change live-domain configuration unless Guy explicitly asks to publish, deploy, or push the current batch live.
- A request to edit, update, fix, preview, or review the portfolio is local-only by default.
- When publishing is explicitly requested, deploy the validated batch as one release and verify the live domain afterward.
